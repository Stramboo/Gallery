# 主页 UI 升级

2026-10-14：项目所有者提供浅色产品主页截图并要求仿照升级，此请求替代主页原有的深色视觉方向。作品索引、分类筛选、灯箱与关于页的功能保持原样。

## 方向

首页借鉴参考图的低高度导航、浅灰全宽画布、居中标题与双按钮，以及首屏下方的深色全宽专题。把产品设备阵列转成三张错落的摄影印样；访客可以从画面直接进入对应摄影分类。手机上保留三图组合并压缩尺寸，专题内容改成单列。

## 页面与交互

- 主色：浅灰 `#f5f5f7`、文字 `#1d1d1f`、操作蓝 `#0066cc`；夜景专题为深色。
- 首屏：光影集品牌、原有中文介绍、浏览作品与关于我、风景／街拍／黑白三张图片。
- 下方：街拍专题、风景与黑白并列专题、作品集入口和示意图片来源。
- 复用现有 React Router 路由；导航根据所在页面选择浅色或暗色样式。
- 移动菜单具有展开状态与关联区域，关闭时不参与键盘导航。
- 不加入参考截图中的地区选择、购物和预订控件。

## 验证

运行现有 `npm run check`、`npm run lint` 和 `npm run build`。检查桌面与手机渲染、图片加载、移动菜单、分类导航以及非主页暗色样式。

本轮结果：三项命令均通过；设计机械扫描未报告问题。浏览器检查覆盖 1440×1000、390×844 和 320×740，六个主页图片实例均加载成功，无横向溢出或 JavaScript 异常；分类跳转、移动菜单展开／关闭以及非主页导航样式均通过。独立截图与源码复核结论为 ship；未测试辅助技术。
